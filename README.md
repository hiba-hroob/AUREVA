# ✨ AUREVA — Salon Management System

**AUREVA** is a modern salon management web application designed to simplify daily salon operations through an elegant and organized interface.

The project brings client records, appointments, staff, services, and business insights together in one place, combining functionality with a refined visual experience.

## 🏗️ Application Architecture

AUREVA follows the **Model-View-Controller (MVC)** architectural pattern.

* **Models:** Represent application data and business entities.
* **Views:** Render the user interface using Razor.
* **Controllers:** Handle requests and coordinate application logic.
* **Entity Framework Core:** Manages database access.
* **PostgreSQL:** Provides relational data storage.
